HashSet Internal Working — Complete Interview Answer
1️⃣ Definition

"HashSet is a collection class in Java that implements the Set interface.
It stores unique elements only and does not maintain insertion order."

2️⃣ Underlying Data Structure

"Internally, HashSet is backed by a HashMap.
Every element of the HashSet is stored as a key in the HashMap, and all keys point to a dummy constant value, usually called PRESENT.
HashSet does not care about values; it only uses the keys to store elements."

3️⃣ How Elements are Added

"When we call hashSet.add(element), internally it does hashMap.put(element, PRESENT).

First, it calculates the hashCode of the element to find the correct bucket in the HashMap.

Then it uses the equals() method to check if the element already exists in that bucket.

If the element does not exist, it is added.

If it already exists, it is ignored.
This is how duplicates are avoided.

What is hashCode()?

In Java, hashCode() is a method that returns an integer value (a hash value) for an object.
It is used to efficiently store and retrieve objects in hash-based collections like:

HashMap

HashSet

Hashtable

🔍 Why is hashCode() important?

Because hash-based collections use the hash code to decide which bucket an object will be placed in.
A good hash code improves search performance.

🔗 Relationship between equals() and hashCode():

If two objects are equal (equals() returns true),
→ they must have the same hashCode.

But if hashCode is the same, they may or may not be equal.

Question:

Aapko ek method likhni hai jo ek List<Integer> ko input le aur return kare saaray unique elements jo list mein do baar ya usse zyada baar aaye ho, ascending order mein.

Example:

Input: [4, 5, 6, 4, 2, 6, 7, 6]
Output: [4, 6]

Challenge:

Aap HashMap ya Streams ka use kar sakte ho.

Complexity ko optimize karne ki koshish karein.

1️⃣ HashMap ke saath solution
import java.util.*;

public class DuplicateElements {
    public static List<Integer> findDuplicates(List<Integer> list) {
        Map<Integer, Integer> countMap = new HashMap<>();
        for (Integer num : list) {
            countMap.put(num, countMap.getOrDefault(num, 0) + 1);
        }

        List<Integer> result = new ArrayList<>();
        for (Map.Entry<Integer, Integer> entry : countMap.entrySet()) {
            if (entry.getValue() >= 2) {
                result.add(entry.getKey());
            }
        }

        Collections.sort(result); // ascending order
        return result;
    }

    public static void main(String[] args) {
        List<Integer> numbers = Arrays.asList(4, 5, 6, 4, 2, 6, 7, 6);
        System.out.println(findDuplicates(numbers)); // Output: [4, 6]
    }
}

Explanation:

HashMap me har number ki count store ki.

Jo numbers 2 ya usse zyada baar aaye, unko result me add kiya.

Last me Collections.sort() se ascending order me sort kiya.

✅ Complexity: O(n log n) (sorting ke liye)
✅ Space: O(n)

2️⃣ Java 8 Streams ke saath solution
import java.util.*;
import java.util.stream.*;

public class DuplicateElementsStream {
    public static List<Integer> findDuplicates(List<Integer> list) {
        return list.stream()
                .collect(Collectors.groupingBy(n -> n, Collectors.counting()))
                .entrySet().stream()
                .filter(e -> e.getValue() >= 2)
                .map(Map.Entry::getKey)
                .sorted()
                .collect(Collectors.toList());
    }

    public static void main(String[] args) {
        List<Integer> numbers = Arrays.asList(4, 5, 6, 4, 2, 6, 7, 6);
        System.out.println(findDuplicates(numbers)); // Output: [4, 6]
    }
}

Explanation:

Collectors.groupingBy se frequency map bana liya.

.filter se sirf count >=2 wale elements liye.

.map se keys liye aur .sorted() se ascending order me sort kiya.
