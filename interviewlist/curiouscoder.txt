HashMap vs IdentityHashMap
HashMap:
HashMap stores data in key-value pairs.
It uses the equals() and hashCode() methods to compare keys.
duplicate logical keys not allowed 
String key1 = new String("Java");
String key2 = new String("Java");

HashMap<String, Integer> map = new HashMap<>();
map.put(key1, 100);
map.put(key2, 200);

System.out.println(map.size()); // Output: 1
Because key1.equals(key2) is true, the second value replaces the first one.

IdentityHashMap:
IdentityHashMap also stores data in key-value pairs.
It compares keys using the == operator (reference equality), not equals().
duplicate logical keys allowed if different reference.
String key1 = new String("Java");
String key2 = new String("Java");

IdentityHashMap<String, Integer> map = new IdentityHashMap<>();
map.put(key1, 100);
map.put(key2, 200);

System.out.println(map.size()); // Output: 2
Because key1 and key2 are different objects in memory, both entries are stored.

HashMap compares keys using equals() and hashCode(), whereas IdentityHashMap compares keys using reference equality (==).
