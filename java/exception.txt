What is the difference between throw and throws in Java?

Feature	throw	throws
Purpose	Used to actually throw an exception	Used in method signature to declare exceptions that method might throw
Where Used	Inside method body	In method declaration
Number of Exceptions	Only one exception can be thrown at a time	Can declare multiple exceptions separated by comma
Checked/Unchecked	Can throw both checked and unchecked exceptions	Mainly used for checked exceptions
Example	throw new IOException("Error");	void readFile() throws IOException, SQLException { }
