what is inversion of control
Inversion of control is a desing principle where instead of our code creating the objects it depends on the framework to do so the framework is responsible for creating the objects managing the life cycle and injecting the depedencies as per the requirement generally on the basis of a configuration file or using annotations consider it like hiring the contractor to buid your house where we tell how the house needs to be created and then the contractor takes the control they further hire the specialist to fulfill our requirement.inversion of control helps in achieving loose coupling and makes us focus more on the business logic spring is a popular framework which helps do so with the help of depedency injection.

runnable vs callable interface
Runnable and Callable are two interfaces used for multithreading in Java. 
Runnable was introduced in Java 1.0, and Callable in Java 1.5. Runnable does not return any value and cannot throw checked exceptions,
 whereas Callable returns a value and can throw checked exceptions. In Runnable, we override the run() method, and in Callable, we override the call() method
