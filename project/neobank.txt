1️⃣ Refined Spoken Answer (for “Can you describe your project?”)

Good morning.
My name is Rahul, and I have over four years of experience as a Backend Developer.
I mainly work with Java, Spring Boot, REST APIs, and PostgreSQL.

For the past fifteen months, I’ve been working on a NeoBanking project called CamPostMoney, which is a digital banking platform in Cameroon.

The system allows users to manage wallets, send and receive money, pay merchants, withdraw cash, take micro-loans, and perform international remittances.

The platform has four main portals —

Customer Portal for wallet management, payments, transaction history, and loan requests.

Agent Portal where agents handle deposits, withdrawals, and customer transactions.

Manager Portal for transaction approvals and performance analytics.

Admin Portal for system configuration, user management, and reporting.

I was responsible for developing and maintaining the backend APIs for all these portals using Spring Boot and PostgreSQL.

In the authentication module, I built secure login, forgot/update password APIs, Two-Factor Authentication using OTP via SMS or Email, and a Refresh Token mechanism supporting multiple roles (Customer, Agent, Manager, Admin, Merchant).

For transactions, I developed APIs for:

Wallet-to-wallet transfer with duplicate transaction checks

Merchant payments (initiation + confirmation)

Cash-out / withdrawal APIs with retry mechanisms and validation

Balance & transaction history APIs

Transaction limits applied per customer

I also integrated international remittance and external top-up APIs.

For Managers and Admins, I implemented approval workflows, user management, analytics, and audit logging to ensure traceability.

On the data management side, I built import/export APIs to handle large datasets in CSV, Excel, or PDF formats — including streaming exports for real-time audit data.

Additionally, I implemented custom frequency execution, which allows scheduled merchant payments to process automatically every few seconds.

On the analytics front, I designed APIs that aggregate transaction, merchant, and communication metrics from different journal and log tables.

I used PostgreSQL for data storage — with encryption, validation, and auditing at both API and database levels.
I also managed schema evolutions for new business requirements like merchant_collector_product and gateway_remittance.

Overall, this project made CamPostMoney NeoBank a secure, scalable, and fully digital financial platform.
It significantly improved transaction reliability, reduced operational errors, and enhanced customer experience.

Through this project, I’ve strengthened my expertise in secure API design, financial transaction handling, and FinTech architecture.

💡 2️⃣ Domain Explanation (if asked “Which domain?” or “Why FinTech?”)

This project belongs to the FinTech domain, because it deals with digital wallets, payments, micro-loans, and remittance services — all of which fall under Financial Technology.

A NeoBank is basically a 100% digital bank — no physical branches, everything happens online via mobile or web.
Unlike traditional banks, NeoBanks rely heavily on secure APIs and real-time integrations for faster and more convenient banking.
