it will be true.
String s1="Java";
String str="Ja";
String s2=str+"va";
System.out.prinlt(s1==s2);
And what will be the output now?
now it will be false.
can you explain the the logic 
start with 1st case:
ja and va are string literals.
the compiler combines them into "Java" at compile time.
ok so
we already have "Java" in the memory because of s1.
So another java will not be created.
s2 will also point towards it.hence s1==s2 will be true.
what about the 2nd case?
Ja is in a variable .its value is only available at runtime.
so,concatenation will take place at runtime.
but str has "Ja".we can clearly see.
yes but java does not treat it that way.
it cant consider str+"Ja" as a compiler time consant.
ok so what happens?
since concatenation happens at runtime "Java" is created as a new String Object.
s1 and s2 point differently hence output is false.

No,once consumed they cant be reused.

yes using Arrays.stream().
