it reduces the need for complex configuration and setup.
it helps developers build production ready application quickly with minimal effort.

what is spring boot used?
spring boot is used to speed up application development by reducing boiler plate code and manual configuration.
it provides built in tools and configuration that make development easie and more effiecient.
it is widely used for building web application ,rest api,microservices,and enterprice applications.

what is the difference between spring and spring boot?
spring requires more manual configuration and setup using xml files or java configuration.
spring boot provides automatic configuration based on the project dependencies and sensible default settings.
spring boot makes development faster by redusing setup effort ,boilerplate code and configuration.

what is the purpose of @RestController?
@RestController is a stereotype annotation used to create restful webservices.
it is a combination of @Controller and @ResponseBody.
it indicates that the class handles http requests and returns data in the response body.

what is the purpose of @Service annotation?
@Service is a stereotype annotation used to mark a class as a service layer component.
it indicates that class contains business logic.

what is the purpose of @Repository annotation?
@Repository is used to mark a class as a data layer access component.
it indicates that the class is responsible for database operaation.

what is the purpose of @Configuration annotation?
@Configuration is used to indicate that a class contains spring configuration.
the class can define one or more @Bean methods to create and manage beans.
it is an alternative to xml based configuration.

what is the purpose of @Bean annotation?
@Bean is used in a @Configuration class to define a bean.
it tells spring to create an object of the methods return type and manage it in the application context.
it is useful when third party classes cant be annotated with spring annotations.

what is the purpose of @Autowired annotation?
@Autowired is used to automatically inject dependencies into a bean.
it can be used on constructors,fields or setter methods.
it tells spring to resolve and inject the required bean from the application context.

what is the purpose of @Value annotation?
@Value is used to inject values from properties file or environement properties.
it can be used on fields constructor parameter or setter methods.
it helps externalize configuration by mapping property values to variables.

what is the purpose of @RequestMapping annotation?
@RequestMapping is used to map http requests to handler mathods in a controller.
it can be applied at the class level or method level.

what is the purpose of @PathVariable annotation?
@PathVariable is used to extract values from uri path.

what is the purpose of @RequestParam annotation?
@Request param is used to extract query parameter from the requets.
it binds the value of a request paramter to a method parameter.

what is the purpose of @RequestBody annotation?
@RequestBody is used to bind the http request body to a method parameter.
it is commonly used in post put and patch requests.
it automatically convert the requets body (usually json) into a java object.

what is the purpose of @ResponseBody annotation?
@ResponseBody is used to return the response directly in the body.
it converts the returned object into json or xml and sends it to the client.
it it often used in combination with @Controller.

what is the purpose of @CrossOrigin annotation?
@CrossOrigin is used to enable cross origin resource sharing.
it allows requests from different domains to access the applications resources.
it can be applied at the class level or method level.

what is the purpose of @ExceptionHandler annotation?
@ExceptionHandler is used to handle exceptions in a centralized way.
it can be used in a controller or in a @Controller Advice class.

what is the purpose of @ControllerAdvice annotation?

@Transactional is used to manage database transactions.

what is hibernate?
hibernate is an open source java orm framework.
it maps java classes and objects to database tables and rows.
it reduces the amount of jdbc and sql boilerplate code.
it provides features like caching ,lazy loading ,dirty checking,and transaction management.

what is orm?
orm stands for object relational mapping.
it is a technique for mapping objects to relational database data.
it maps java classes to database tables and java objects to table rows.
it allows developers to work with database data using java objetcs instead of writing sql queries manually.

what is session factory in hibernate?
session factory is an interface in hibernate.
it is heavy weight and created once per database.
it acts as a factory for creating session objects .
it is thread safe and should be closed when the application is shut down.

what is session in hibernate?
session in an interface that provides a connection between the application and the database.
it is light weight and not thread safe.
it used to perform crud operations.
it has a first level cache called persistence context.

what is persistence context in hibernate?
persistence context is a first level cache in hibernate.
it stores the managed entity objects within a session.
it ensures that the same object is returned for multiple databse requests in a session.
it helps in tracking changes made to entities and synchronizes them with the database.

what is lazy loading in hibernate?
lazy loading is a desing pattern used to delay the loading of an object until it is needed.
it is enabled by default for associations in hibernate.
it improves performance by reducing unnecessary databse calls.
if the associated object is not accessed it is never loaded from the database.

what is dirty checking in hibernate?
dirty checking is a feature in hibernate that detects changes made to an entity.
hibernate automatically compares the in memory state of the entity with the databse state.
if any changes are found hibernate automatically synchronizes them with the databse during flush.
this reduces the need to manually update the entity in the database.

what is transaction maangement in hibernate?
transaction management ensures data consistency and integrity.
hibernate supports both programatic and declarative transaction management. 
it integrates with jdbc transactions to ensure acid properties .
transactions are committed if everything is successful otherwise rolled back in case of an error. 

what is caching in hibernate?
caching is a mechanism to store frequently accessed data in memory.
hibernate provides first level cache(session level)and second level cache (session factory level).
it reduces the number of database hits and improves application performance.
cached data is reused for the same requests within the cache scope.

what is n+1 select problem in hibernate?
the n+1 select problem occurs when hibernate executes one query for the parent entity and n additional queries for the child entities.
it happens due to lazy loadeding of associations.
it leads to poor performance becuase of multiple database calls.
it can be solved using fetch join,entitygraph,or batch fetching.

what is fetch join in hibernate?
fetch join is used to fetch associated entities along with the parent entity in a single query.
it helps in solving the n+1 select problem.
it is done using join fetch in hql or criteria api.
it improves performance by reducing the number of sql queries.

what is entitylife cycle in hibernate?
the entity life cycle refers to the different states an entity goes through in hibernate.
the main states are transient,persistent ,detached,removed.
it helps in understanding how hibernate manages entity objects.
state transitions are managed by methods like persist(),save(),merge(),remove() and detach().

what is lazy loading in hibernate?
lazy loading delays the loading of associated entities until they are needed.
it improves performance by loading only required data.
it is enabled by default for collections can be enabled for to one associations.
when the related data is accessed hibernate loads it on demand.

what is eager loading in hibernate?
eager loading loads associated entities immediatly along with the parent entity.
it is useful when the associated data is always required .
it can be enabled using fetch join ,criteria api,or setting fetchType.Eager.
overuse of eager loading can impact performance by fetching unnecessary data.
