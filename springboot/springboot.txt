1.Difference between @PathVariable and @RequestParam
@RequestParam extracts query parameters from the URL (e.g., /search?name=john), whereas @PathVariable extracts values directly from the URI path (e.g., /users/1).

Summary Table: Parameter Extraction
Feature 	@RequestParam	@PathVariable
URL Example	/api?id=10	/api/10
Default Required	Yes (can be changed)	Yes
Best Use Case	Optional filters, pagination	Identifying specific resources
Multiple Values	Supported (List/Array)	Not supported for single path segment

2.What happens if a parameter is missing in the request?
By default, @RequestParam is required. If a client omits it, Spring Boot returns a 400 Bad Request. To avoid this, you can set required = false or provide a defaultValue.

3.How to handle multiple values for the same parameter?
If a URL contains ?id=1&id=2, you can map it to a List<Long> ids or an array Long[] ids in your controller method.

4.Can you map query parameters to a POJO?
Yes. Instead of using multiple @RequestParam annotations, you can use a Data Transfer Object (DTO)  (POJO) without any annotation. Spring will automatically bind matching query parameters to the fields of that object.

5.How do you handle special characters or naming mismatches (e.g., snake_case to camelCase)?
If a query parameter is named book_id but your Java field is bookId, you must explicitly specify the name: @RequestParam("book_id") String bookId.

5.Can you read all query parameters dynamically?
Yes, by using a Map<String, String> with the @RequestParam annotation. This captures all parameters into a single map regardless of their names.

7.Design a REST endpoint that filters products by type. If type is missing, return all products.
Answer: Use @RequestParam(value = "type", required = false) String type. In your logic, check if type is null to decide whether to filter or return all results.
Scenario: Validation

8.How do you validate a @RequestParam (e.g., ensuring a age parameter is over 18)?
Answer: Annotate your controller with @Validated and use Bean Validation  annotations like @Min(18) directly on the method parameter: @RequestParam @Min(18) int age.
