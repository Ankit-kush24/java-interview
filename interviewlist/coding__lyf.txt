JVM(java virtual machine)
what it is:the core engine that runs java programs by converting bytecode into machineCode.
role:executes java program,manage memory,and performs garbage collection.
key point:it is platform dependent but ensures javas write once run anywhere capability.

JRE(java runtime environment):
what it is:A package containing the jvm and the necessary libraries ,files,and tools to run java applications.
role:provides the environment to execute java programs.
key point:only for running java applications does not include development tools.


jdk(java development kit):
what it is:A superset of jre that includes tools like a compiler ,debugger,and libraries for developing java applications.
role:Allows you to write ,compile and debug java programs.
key point :used for development ,with jre bundled inside.

method overriding:method overriding is when a child class provides its own specific implementation of a method that is already defined in its parent class,but with the same name ,parameters and return type.
real world example:imagine a payment system:
A generic payment method exists in the parent class.
child classes like creditcard payment and upipayment override the method to implement payment logic specific to their type.
