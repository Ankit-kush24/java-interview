What is the difference between Authentication and Authorization?
Authentication is the process of verifying who a user is (e.g., login with credentials).
Authorization is the process of determining what an authenticated user is allowed to do (e.g., checking roles like ADMIN or USER).
-------------
How does the DelegatingFilterProxy work?
It is a standard Servlet Filter that bridges the Servlet container’s lifecycle and Spring’s ApplicationContext. It delegates the actual work to a Spring-managed bean that implements the Filter interface (typically the FilterChainProxy).
------------
What is the SecurityContextHolder?
This is where Spring Security stores details of the currently authenticated user. By default, it uses a ThreadLocal to store these details, making them available to all methods in the same thread of execution.

Explain the role of the AuthenticationManager.The AuthenticationManager is the main strategy interface for authentication. The most common implementation is ProviderManager, which delegates the authentication request to a list of configured AuthenticationProviders.
------------
What is CSRF and how does Spring Security handle it?Cross-Site Request Forgery (CSRF) is an attack that tricks a user into performing unwanted actions. Spring Security enables CSRF protection by default, requiring a unique, synchronized token to be included in all state-changing requests (POST, PUT, DELETE).

What is the difference between hasRole() and hasAuthority()?hasRole("ADMIN") automatically prefixes the string with ROLE_ (checking for ROLE_ADMIN).hasAuthority("ADMIN") checks for the exact string provided without any prefix.

How do you handle Password Encoding?Spring Security uses the PasswordEncoder interface. The recommended implementation is BCryptPasswordEncoder, which uses a strong hashing function with a built-in salt to protect against rainbow table attacks.

How did you implement role-based access control (RBAC) in your applications?

RBAC is implemented using roles like ADMIN and USER.

Example:

- ADMIN → full access  
- USER → limited access  

Spring Security restricts endpoints based on roles.
