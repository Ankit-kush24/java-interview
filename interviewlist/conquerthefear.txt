what is spring security in spring boot?
spring security in spring boot is a powerful and highly cusomizable framework for adding authentication and authorization to your sprign boot applications.

what is spring security?
Authentication:this is the process of verifying who a user is.it typically involves the user providing credentials like a username and password which are then checked againts datasource like a database or ldap server spring security support various authentication mechanism.

OAuth 2.0:used for third party authentication login with google or facebook.
saml: single sign on in enterprce environemnt.

Authorization:after a user is authenticated authorization determines what the user is allowed to do.is is about granting or denying access to specific resources or functionalities spring security provides role based and 	permission based authorization.

RoleBased:assigning users to roles (exa ADMIN USER)and granting access based on those roles.
permission based:fine grained control over access based on specific permissions.

security context:	spring security uses a SecurityContextHolder to store the currently authenticated users information (principle or authorities).
