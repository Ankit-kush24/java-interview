201.What is the difference between @component @service @repository and @controller in spring?
all four are spring beans meaning spring will detect them and manage them in the container.
@Component is the generic one - i use it for utility classes or helpers where there is no specific layer meaning.
@Service is for business logic layer like where you write validation orchestration and core flow.
@Repository is for data access layer like DAO or spring Data Repository and it also helps with exception translation into Spring's DataAccessException.
@Controller is for web layer - it handles incoming HTTP requests and returns response views or JSON (with @RestController).
